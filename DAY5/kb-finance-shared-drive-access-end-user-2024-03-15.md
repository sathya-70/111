# Finance Shared Folder Help (Easy Self-Help)

Version: v 1.0  
Date: 07/08/2026  
Status: Draft

## What this is about
If you cannot open the Finance team folder, follow these steps.

Your files are safe. This problem does not delete your documents.

## What you can do now
1. Save any work you have open.
Expected result: Your latest changes are saved.

2. Sign out of your computer.
Expected result: Your sign-in closes.

3. Wait 2 minutes.
Expected result: The computer has time to finish setup in the background.

4. Sign back in.
Expected result: Your normal desktop appears.

5. Open the folder window.
Expected result: The folder window opens.

6. Open the Finance folder shown as S:.
Expected result: The Finance folder opens.

7. If you cannot see S:, type \\finbridge-fs01\Finance in the top address box in the folder window, then press Enter.
Expected result: The Finance folder opens directly.

## If it is still not working
Contact the IT help team if you still cannot open S: or \\finbridge-fs01\Finance after signing out and signing back in once.

## Details to include in your ticket
- Your full name
- Your work sign-in name
- Your computer name (example: DESKTOP-XXXX)
- Your location (office or home)
- The time the problem started
- What you already tried
- What happened (include the exact message, if shown)
- Whether nearby coworkers have the same problem
- A picture of the error message (if possible)
